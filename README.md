<details>
<summary><b>🧩 Pattern Recognition Guide</b> — click to expand</summary>

<br/>

| If the problem involves... | Think about... |
|----------------------------|----------------|
| Sorted array + target sum | Two Pointers |
| Subarray / substring of size k | Sliding Window |
| Find if something exists in unsorted data | Hash Set |
| Find complement / pair | Hash Map |
| All combinations / permutations | Backtracking |
| Optimal choice at each step | Greedy |
| Overlapping subproblems | Dynamic Programming |
| Tree traversal | DFS (recursion) or BFS (queue) |
| Shortest path (unweighted) | BFS |
| Shortest path (weighted) | Dijkstra / Bellman-Ford |
| Next greater / smaller element | Monotonic Stack |
| Top K elements | Heap / QuickSelect |
| Divide into halves | Binary Search |
| Connected components | Union-Find / DFS |

</details>

<details>
<summary><b>📐 Space Complexity Rules of Thumb</b> — click to expand</summary>

<br/>

- **O(1)** — Two pointers, in-place swaps, constant extra variables
- **O(log n)** — Recursive binary search (call stack depth)
- **O(n)** — Hash maps, auxiliary arrays, BFS queue
- **O(n²)** — 2D DP tables, adjacency matrix
- **O(n + m)** — Adjacency list graphs (n vertices, m edges)

</details>
